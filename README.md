# Collaborative Modular Calculator

Hands-on workshop to practice Git workflows (branches, commits, pull requests) and modular Java development using GitHub Codespaces.

---

## 🚀 Team Assignments

* **Team 1 (Contract):** Create `Operation.java` interface.
  * Branch: `feature/operation-contract`
* **Team 2 (Basic Ops):** Implement `Addition.java` and `Subtraction.java`.
  * Branch: `feature/basic-operations`
* **Team 3 (Advanced Ops):** Implement `Multiplication.java` and `Division.java`.
  * Branch: `feature/advanced-operations`
* **Team 4 (Runner):** Implement `Main.java` to test all operations.
  * Branch: `feature/main-runner`
